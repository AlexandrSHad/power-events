# PlatformIO Build

Build command: `pio run`

For specific project:
- esp32: `-d D:\test-projects\power-events\esp32`
- esp32-display: `-d D:\test-projects\power-events\esp32-display`

Upload: Add `-t upload` flag
Clean: Add `-t clean` flag
